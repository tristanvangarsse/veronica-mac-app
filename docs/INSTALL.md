# Install Veronica beta

Download the `.dmg` attached to the [GitHub beta release](https://github.com/tristanvangarsse/veronica-mac-app/releases). Veronica currently requires an **Apple Silicon Mac running macOS 26 or later**.

1. Open the downloaded disk image.
2. Drag **Veronica** into **Applications**. If you do not have permission to install for all users, create an **Applications** folder inside your own Home folder and copy Veronica there.
3. Eject the disk image, then open the installed copy.
4. First launch checks and prepares the built-in tools automatically. Python, Homebrew and separate media-tool installations are not needed.

This beta is not signed with an Apple Developer ID or notarized by Apple. macOS may block the first opening. If you trust this download, follow [Apple’s instructions](https://support.apple.com/102445) in **System Settings → Privacy & Security → Open Anyway**. Your Mac may require administrator approval. Keep macOS security protections enabled.

Start with copies of a small test folder. Review the proposed changes before Smart cleanup. Replaced originals go to the Mac Trash. Keep them there until you have checked the results; emptying Trash permanently removes those originals.

## Update

Quit Veronica. Download and open the next release’s disk image, then replace the installed application. Your folder preferences and change logs are stored separately in your Library and remain in place. Open the new copy and run a fresh scan.

## Help

Use [GitHub Issues](https://github.com/tristanvangarsse/veronica-mac-app/issues) for problems. Include the app version, macOS version and steps to reproduce. Settings → Support can export a diagnostic report. Review attachments before publishing them, and do not attach personal media or change logs containing private file paths.
