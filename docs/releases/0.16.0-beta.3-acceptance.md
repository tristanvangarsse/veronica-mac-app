## Evidence boundaries and beta limitations

The earlier build-9 stress test completed a 3,000-file mixed-library run, verified recoverable originals and performed a fresh-session repeat cleanup with zero further changes. Its abrupt-termination test retained all 24 original hashes and completed after restart. Those are earlier-build evidence; the complete 3,000-file workload was not repeated for build 13. Current recovery and format changes have focused source/frozen-engine checks and the native workflow above.

Each new launch scans afresh. Already optimized files can appear as candidates again; replacements are only installed if they pass verification and meet the folder's saving targets. In the repeat native test, every output byte remained unchanged. Large-library performance and more codec/storage combinations remain useful beta feedback.

This is one physical Mac. No claim is made for Intel, older macOS releases, another physical Mac or indefinite compatibility with future systems. The first-download Gatekeeper approval was not repeated in this temporary-profile test. Offline dependency denial is covered by the clean-install regression. Processing uses generated copies; broader real-library testing belongs to the public beta and should begin with disposable copies and backups.

Feedback: Settings → Support → Report a problem or share beta feedback, the GitHub issue forms. Reports are never uploaded automatically; testers should remove private information before attaching screenshots or diagnostic ZIPs.
