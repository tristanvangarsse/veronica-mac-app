## Automated release checks

- All 53 regression scripts, the Python dependency advisory check and the native macOS build passed in GitHub CI for the app source commit.
- Exact final DMG: strict app signature, runtime manifest, current dependency notices, minimum macOS declaration and cross-account resource readability passed.
- Relocated bundled runtime performed real image, video and audio conversions and manual date editing. Media helpers ran with developer-tool locations and networking denied. Missing bundled executables/libraries were refused safely, without falling back to installed tools.
- Matching sources, build recipes and notices for 58 third-party components were collected. The five GitHub draft asset digests matched their local files.

## Native desktop acceptance

The unchanged app copied from the DMG was operated through its normal macOS interface with a temporary profile and generated media. Version 0.15.0 was configured first, then replaced with the exact beta build.

- Fresh profile opened at Add folders without inherited settings.
- Two folders retained independent photo, video, audio and exclusion settings. A named photo preset was saved, replaced with another preset and applied again successfully.
- Cancelling a scan returned to the folder screen and left generated source hashes unchanged.
- Upgrade to build 8 retained folder settings and the saved preset byte for byte.
- Review expanded the window and showed the planned changes. A skipped JPEG had the correct exclusion explanation.
- A missing date was set to 3 February 2020 through the inspector and verified in output metadata.
- Smart cleanup optimized six files. Photos were reduced to approximately one megapixel, video became H.264 at 854 × 480, and audio became MP3 at 128 kbps.
- Four protected, recent, skipped or unreadable sources stayed byte for byte unchanged.
- Separate dated manual-date and cleanup logs recorded the changes and three moves of replaced originals to Trash. macOS privacy protection prevented direct command-line hashing inside Trash; exact-original recovery is covered by the automated checks.
- Quit/reopen retained both folders and their settings, with a fresh scan session.
- The normal profile and macOS app preferences were restored and checked against the pre-test backup. A second prepare/restore smoke test verified nested-session refusal and repeatable restoration.

## Limits

This is an Apple Silicon/macOS 26 beta without Developer ID signing or Apple notarization. Gatekeeper approval remains a user action. No claim is made for Intel Macs, older macOS releases or another physical Mac. Routine testing now uses a temporary profile on the current desktop; separate-account and other-Mac download checks remain distinct evidence.
